# Quick Commerce Operational Intelligence Dashboard

This project analyzes quick-commerce operations across companies such as Blinkit, Zepto, Swiggy Instamart, Dunzo, Amazon Now, Big Basket, Flipkart Minutes, and JioMart.

Note: Large dataset files are excluded due to GitHub file size limitations.

## Features
- Delivery Time Prediction
- Discount Prediction
- Operational Load Analysis
- Dark Store Utilization Analysis
- Customer Rating Insights
- Peak Hour Analysis
- Revenue & Demand Trends

## Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- HTML/CSS/JavaScript
- Plotly

## Dataset
45,301 quick-commerce orders across multiple Bangalore regions.
